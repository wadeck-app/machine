## Summary

`machine` is a CLI + background daemon that links the user's personal machines (Mac M2, Win11 work laptop, Win10 desktop, Linux box) into one private network. Machines register through the poc-node server (Infomaniak) and then exchange authenticated, encrypted messages. On top of it: remote command execution and "remote" plugins so task, flow, queue and orch can address a remote machine like the local one. Target size: a handful of machines. Security is the first constraint (see `threat-model.md`).

Evidence base: reports on task, queue, orch, project, poc-node (see `evidence.md`).
